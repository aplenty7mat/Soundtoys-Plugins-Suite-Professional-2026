## Veelgestelde Vragen (FAQ)

### Kan ik de Soundtoys-Plugins op Windows 10 gebruiken?
Ja, de Soundtoys-Plugins Professional Suite 2026 is volledig compatibel met Windows 10 (versie 1903 of hoger) en Windows 11. Beide besturingssystemen worden volledig ondersteund op 64-bit architectuur.

### Welke DAW software wordt ondersteund?
De Soundtoys-Plugins zijn compatibel met alle gangbare DAW software die VST, VST3 of AAX plugins ondersteunt, waaronder FL Studio, Ableton Live, Logic Pro, Cubase, Pro Tools, Studio One, Cakewalk en Reaper.

### De installatie loopt vast, wat moet ik doen?
Probeer de volgende oplossingen: (1) Voer het installatieprogramma uit als administrator, (2) Schakel je antivirussoftware tijdelijk uit, (3) Zorg ervoor dat je voldoende vrije schijfruimte hebt, (4) Controleer of je DAW software gesloten is tijdens de installatie.

### Hoe kan ik de plugins in mijn DAW laden?
Na installatie start je je DAW software. De Soundtoys-Plugins verschijnen automatisch in je plugin bibliotheek. Zoek naar "Soundtoys" in je plugin manager of scan de map waar je de plugins hebt geïnstalleerd.

### Zijn er systeemeisen voor real-time audio verwerking?
Voor optimale prestaties wordt een Intel Core i5 of AMD Ryzen 5 processor en minimaal 8 GB RAM aanbevolen. Gebruik een ASIO-compatibele geluidskaart met een buffergrootte van 256 samples of lager voor minimale latentie.
